# Astana Walks

ИИ-помощник по прогулкам в Астане для задачи №1 НИЦ Smart City, Build with AI / GDG Astana.

Напишите одно сообщение: **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Помощник одновременно проверяет OpenStreetMap, Google и 2ГИС, выбирает до трёх остановок и даёт один цельный ответ. План включает пешие переходы, посещения, запас и возвращение к старту. Единственная Google-карта появляется после построения маршрута.

**Перенос единого интерфейса на основной порт8000 и [публичный HTTPS-адрес](https://entire-burn-cricket-ashley.trycloudflare.com/) подготовлен; фактическое переключение ещё должен подтвердить Codex A.** Локальный8003 остаётся предпросмотром. Адрес работает, пока включены ПК, приложение и туннель.

## Как работает подбор

- Старт берётся из текста в локальном справочнике; если он не указан, браузер запрашивает геолокацию после нажатия, не более8секунд. Неизвестный адрес, отказ/ошибка GPS и старт вне области останавливают поиск **до обращений к источникам и модели**. Подставного городского старта нет.
- Без длительности готовятся варианты60/120/240минут; диапазон даёт минимум, середину и максимум. Время суток определяется по одному снимку часов браузера. Ручных полей уточнения нет.
- Перед кнопкой раскрыта передача Google/2ГИС старта и ограниченных пожеланий. Исходное сообщение целиком в эти API не отправляется. Модель получает публичные факты мест, полный ответ Google и все обязательные previews.
- Google проверяет направленные пешие участки и возврат. Бюджет — верхняя граница10–480минут, а не обещание заполнить всё время. Посещения и5минут запаса предложены приложением.
- Проверенный ответ локальной Qwen показывается целиком. Если генерация не подтверждена, режим обозначен явно и остаются план и полный исходный ответ Google. Ошибка одного источника не выдаётся за успешный объединённый поиск.
- Переключение готового варианта не запускает новый поиск или модель. Обновляется один маршрут на карте. Часы, доступ, розетки, тишина и безопасность могут оставаться неизвестными.

## Запуск

Нужен Python3.11+, уже работающий loopback endpoint локальной модели и существующие приватные конфигурации Google,2ГИС и отдельного Maps Embed key. Backend использует стандартную библиотеку; Node.js нужен для frontend-тестов, а не для работы сервера.

[Воспроизводимый запуск8000, предпросмотр8003 и откат](docs/DEPLOYMENT.md) · [API, квоты и ограничения](docs/UNIFIED_LAB.md).

Основной сервер — `python -m app.google_lab --port 8000 ... --public-origin https://entire-burn-cricket-ashley.trycloudflare.com`. Полная команда с путями настроек приведена в DEPLOYMENT. Без конфигурации трёх источников единый поиск не подменяется другим режимом.

Закреплённая модель: **Qwen3-4B-Instruct-2507 Q4_K_M**, публикация Unsloth на основе Qwen, llama.cpp b11739 CPU, Apache-2.0. Веса около2,5ГБ и ключи не входят в Git/ZIP. Для первой подготовки модели:

```sh
python scripts/setup_local_llm.py --download
python scripts/setup_local_llm.py --serve --port 8081
```

Не запускайте второй экземпляр, если8081 уже работает. Основной сервер и предпросмотр используют один существующий endpoint. `scripts/run_demo.py`, Dockerfile и `python -m app.server` относятся к прежнему приложению; это не команды запуска единого интерфейса.

## Данные, квоты и установка

OSM-снимок содержит1267 объектов источника; после ограничения доступа для подбора доступны1266. Происхождение, raw/query, даты и SHA — в [data/SOURCES.md](data/SOURCES.md). Это ограниченная область Астаны, не полный каталог. Google и2ГИС запрашиваются вживую; пустые результаты и вклад каждого источника видны отдельно.

Сохраняются общие существующие лимиты: **500 Google backend HTTP-попыток** всего пилота и **20 попыток2ГИС за скользящие24часа**, включая ошибки. Новый процесс или8003 не создаёт новый бюджет. Браузерная карта использует отдельный намеренно публичный ключ только Maps Embed API, ограниченный пятью разрешёнными referrers; backend key браузеру не передаётся.

Объединённые ответы, данные2ГИС, исходные сообщения и GPS не записываются в историю, RAG, ответный кэш или сырые QA-файлы. Карта использует RAM ticket на600секунд. Исторический29-дневный архив отдельных Google endpoints к единому ответу не применяется.

Установка доступна средствами браузера; при наличии системного предложения появляется кнопка «Установить». Сохранены прежние manifest id/start_url/scope. Новый service worker хранит только оболочку интерфейса; API, запросы, координаты, ответы и Google-карта не кэшируются. Без сети можно открыть оболочку, для нового подбора нужны backend и интернет. Прежнее подтверждение установки в Android Chrome относится к прежней версии; новая версия требует отдельной фактической проверки.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Node.js в PATH включает автономные JS-проверки интерфейса и PWA. Они используют mock DOM/fetch/geolocation и не доказывают реальную работу провайдеров, GPS или телефона. Фактические проверки и source SHA — в [qa/unified-search-check.json](qa/unified-search-check.json); исходы без принятого текста остаются отрицательными. Метаданные не содержат приватных запросов/координат или сырых данных провайдеров.
