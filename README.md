# Astana Walks

ИИ-помощник по прогулкам в Астане для задачи №1 НИЦ Smart City, **Build with AI / GDG Astana**.

**[Открыть демо](https://ltybcs.com/demo)** · [Публичный код](https://github.com/ltybcs/astana-walks-ai)

Напишите: **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Помощник подбирает до трёх остановок и показывает один маршрут с возвращением к старту.

## Как работает подбор

Локальная **Qwen3-4B-Instruct-2507 Q4_K_M** выделяет из сообщения цель, место старта и ограничения. Проверенный план намерения передаётся всем источникам; знакомые формулировки **31 категории** доступны и через резервный разбор. Дополнительные типы мест требуют подтверждения структурированными данными источника: модель не превращает похожее занятие в выполненное пожелание.

Старт определяется по публичным ориентирам и локальному каталогу. Явно названное незнакомое место может быть проверено через Google Places; если место не указано, запрашивается GPS. Без подтверждённого старта поиск занятий, маршруты и итоговый ответ не запускаются.

OpenStreetMap, Google и 2ГИС проверяются параллельно. RAG отбирает подходящие факты, а локальная модель формулирует общий ответ и отдельное описание каждой остановки по её собственному источнику. Полный ответ Google и все обязательные источники доступны в раскрываемом пояснении. Часы, розетки, оборудование и другие неизвестные свойства не выдаются за факты.

Google рассчитывает направленные пешие участки, включая возвращение. В бюджет входят переходы, предложенное время посещений и запас. Без длительности готовятся варианты 60/120/240 минут; они переключаются без нового поиска. Карта появляется после построения маршрута.

## Запуск и проверка

Нужны Python 3.11+, интернет, локальная модель через llama.cpp и настроенные Google, 2ГИС и Maps Embed API. Ключи и веса не входят в репозиторий. Backend использует стандартную библиотеку Python; Node.js нужен для frontend-тестов.

Команды и конфигурация — в [инструкции запуска](docs/DEPLOYMENT.md), примеры — в [сценариях](docs/CURRENT_SCENARIOS.md).

```sh
python -m unittest discover -s tests -v
```

Автономные тесты используют подмены API, DOM и геолокации. Они не подтверждают универсальное понимание запросов, живое покрытие всех категорий или проверку на физическом телефоне.
