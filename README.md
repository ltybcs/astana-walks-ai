# Astana Walks

ИИ-помощник по прогулкам в Астане для задачи №1 НИЦ Smart City, **Build with AI / GDG Astana**.

**[Открыть демо](https://ltybcs.com/demo)** · [Публичный код](https://github.com/ltybcs/astana-walks-ai)

Напишите: **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Помощник подбирает до трёх остановок и показывает один маршрут с возвращением к старту.

## Как работает подбор

Лексический разбор распознаёт **31 категорию** занятий, время и известные ориентиры. OpenStreetMap, Google и 2ГИС проверяются параллельно; происхождение мест и состояние каждого источника видны отдельно. Локальная **Qwen3-4B-Instruct-2507 Q4_K_M** формулирует один ответ по найденным данным. Полный ответ Google и все обязательные источники доступны в раскрываемом пояснении.

Google рассчитывает направленные пешие участки, включая возвращение. В бюджет входят переходы, предложенное время посещений и запас. Без указанной длительности готовятся варианты 60/120/240 минут; готовые варианты переключаются без нового поиска. Карта появляется после построения маршрута.

## Запуск и проверка

Нужны Python 3.11+, интернет, работающая локальная модель через llama.cpp и настроенные Google, 2ГИС и Maps Embed API. Ключи и веса модели не входят в репозиторий. Backend использует стандартную библиотеку Python; Node.js нужен для автономных frontend-тестов.

Полные команды и подготовка конфигурации — в [инструкции запуска](docs/DEPLOYMENT.md).

```sh
python -m unittest discover -s tests -v
```

Автономные тесты используют подмены API, DOM и геолокации. Они не подтверждают работу всех категорий вживую или проверку на физическом телефоне.
