# Astana Walks

ИИ-помощник по прогулкам в Астане для задачи №1 НИЦ Smart City, Build with AI / GDG Astana.

Напишите одно сообщение: **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Помощник одновременно проверяет OpenStreetMap, Google и 2ГИС, выбирает до трёх остановок и даёт один цельный ответ. План включает пешие переходы, посещения, запас и возвращение к старту. Единственная Google-карта появляется после построения маршрута.

**Единый интерфейс развёрнут на основном порту 8000 и [публичном HTTPS-адресе](https://entire-burn-cricket-ashley.trycloudflare.com/).** Загрузка новой оболочки, PWA и отказ без старта проверены через действующий адрес 20 октября 2026; границы живой приёмки указаны в QA-протоколе. Локальный 8003 остаётся предпросмотром. Адрес работает, пока включены ПК, приложение и туннель.

## Как работает подбор

- Цель определяется общим каталогом из **31 категории**: прогулки, парки, набережные, площадки, кафе, рестораны, бары, музеи, театры, архитектура, торговые центры, компьютерные клубы, кино, боулинг, бильярд, караоке, квесты, настольные игры, антикафе, батуты, скалодромы, катки, бассейны, СПА, аттракционы, фитнес, книжные магазины, библиотеки, коворкинги, ночные клубы и аптеки. Локальная модель формулирует ответ после поиска. Общий смысловой разбор произвольных пожеланий пока не добавлен; каталог не означает наличие всех этих типов рядом со стартом.
- Старт берётся из текста в локальном справочнике; если он не указан, браузер запрашивает геолокацию после нажатия, не более 8 секунд. Неизвестный адрес, отказ/ошибка GPS и старт вне области останавливают поиск **до обращений к источникам и модели**. Подставного городского старта нет.
- Без длительности готовятся варианты 60/120/240 минут; диапазон даёт минимум, середину и максимум. Время суток определяется по одному снимку часов браузера. Ручных полей уточнения нет.
- «На пару часов» означает бюджет 120 минут. Запрос «в комп клуб на пару часов рядом с Байтереком» ищет компьютерные клубы во всех трёх источниках и строит путь к одному подходящему заведению. Парки не подставляются вместо клуба. Бюджет включает путь туда и обратно; время сеанса предложено, часы, оборудование и свободные места могут быть неизвестны. Неподдерживаемая явная категория даёт ошибку, а не другую прогулку.
- Для одного заведения основная цель остаётся строгой: кофе не заменяет боулинг. Явное «площадки или музей» ищет обе категории как варианты; семейный контекст сам по себе не доказывает наличие площадки или интерактивов. Тип 2ГИС берётся из возвращённых рубрик, не из бренда или поисковой фразы. Google без структурированного типа не считается подтверждением конкретной категории.
- Из текста распознаются MEGA Silk Way, Байтерек, набережная, EXPO, Центральный и Президентский парки, Abu Dhabi Plaza и аэропорт. У аэропорта используется ориентир T1 из OSM, а не точная позиция человека; регистрация, контроль и посадка не входят в прогулку.
- В компактных «Условиях использования» внизу раскрыта передача Google/2ГИС старта и ограниченных пожеланий. Исходное сообщение целиком в эти API не отправляется. Модель получает публичные факты мест, полный ответ Google и все обязательные previews.
- Google проверяет направленные пешие участки и возврат. Бюджет — верхняя граница 10–480 минут, а не обещание заполнить всё время. Посещения и 5 минут запаса предложены приложением.
- В карточке места есть «Почему»: подтверждённый тип и проверенный бюджет, при наличии — сведения об обязательных свойствах. Полный ответ локальной Qwen, исходный Google summary и все его previews доступны одним раскрытием после маршрута. Если генерация не подтверждена, режим обозначен явно и остаются план и полный исходный ответ Google. Ошибка одного источника не выдаётся за успешный объединённый поиск.
- Переключение готового варианта не запускает новый поиск или модель. Обновляется один маршрут на карте. Часы, доступ, розетки, тишина и безопасность могут оставаться неизвестными.

## Запуск

Нужен Python 3.11+, уже работающий loopback endpoint локальной модели и существующие приватные конфигурации Google, 2ГИС и отдельного Maps Embed key. Backend использует стандартную библиотеку; Node.js нужен для frontend-тестов, а не для работы сервера.

[Воспроизводимый запуск 8000, предпросмотр 8003 и откат](docs/DEPLOYMENT.md) · [API, квоты и ограничения](docs/UNIFIED_LAB.md).

Основной сервер — `python -m app.google_lab --port 8000 ... --public-origin https://entire-burn-cricket-ashley.trycloudflare.com`. Полная команда с путями настроек приведена в DEPLOYMENT. Без конфигурации трёх источников единый поиск не подменяется другим режимом.

Закреплённая модель: **Qwen3-4B-Instruct-2507 Q4_K_M**, публикация Unsloth на основе Qwen, llama.cpp b11739 CPU, Apache-2.0. Веса около 2,5 ГБ и ключи не входят в Git/ZIP. Для первой подготовки модели:

```sh
python scripts/setup_local_llm.py --download
python scripts/setup_local_llm.py --serve --port 8081
```

Не запускайте второй экземпляр, если 8081 уже работает. Основной сервер и предпросмотр используют один существующий endpoint. `scripts/run_demo.py`, Dockerfile и `python -m app.server` относятся к прежнему приложению; это не команды запуска единого интерфейса.

## Данные, квоты и установка

OSM-снимок содержит 1267 объектов источника; после ограничения доступа для подбора доступны 1266. Происхождение, raw/query, даты и SHA — в [data/SOURCES.md](data/SOURCES.md). Это ограниченная область Астаны, не полный каталог. Google и 2ГИС запрашиваются вживую; пустые результаты и вклад каждого источника видны отдельно.

[Поддерживаемые категории, обязательные сценарии и границы](docs/CATEGORY_COVERAGE.md).

Общие лимиты: **500 Google backend HTTP-попыток** всего пилота и, по новому разрешению пользователя, **500 попыток 2ГИС за скользящие 30 дней**, включая ошибки. Для 2ГИС используется прежний ledger; автоматического сброса, новых ledger или пула ключей нет. Новый процесс или 8003 не создаёт новый бюджет. Браузерная карта использует отдельный намеренно публичный ключ только Maps Embed API, ограниченный пятью разрешёнными referrers; backend key браузеру не передаётся.

Объединённые ответы, данные 2ГИС, исходные сообщения и GPS не записываются в историю, RAG, ответный кэш или сырые QA-файлы. Карта использует RAM ticket на 600 секунд. Исторический 29-дневный архив отдельных Google endpoints к единому ответу не применяется.

Установка доступна средствами браузера; при наличии системного предложения появляется кнопка «Установить». Сохранены прежние manifest id/start_url/scope. Новый service worker хранит только оболочку интерфейса; API, запросы, координаты, ответы и Google-карта не кэшируются. Без сети можно открыть оболочку, для нового подбора нужны backend и интернет. Прежнее подтверждение установки в Android Chrome относится к прежней версии; новая версия требует отдельной фактической проверки.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Node.js в PATH включает автономные JS-проверки интерфейса и PWA. Они используют mock DOM/fetch/geolocation и не доказывают реальную работу провайдеров, GPS или телефона. Фактические проверки и source SHA — в [qa/unified-search-check.json](qa/unified-search-check.json); исходы без принятого текста остаются отрицательными. Метаданные не содержат приватных запросов/координат или сырых данных провайдеров. Исправления категории, словесного времени, старта маршрута и мобильной вёрстки описаны в [qa/mobile-intent-check.json](qa/mobile-intent-check.json): прежняя ошибочная карта сохранена как FAIL, живая карта на692630b отделена от более поздних offline-проверок защит.

Итог расширения категорий и компактного интерфейса: [qa/category-coverage-check.json](qa/category-coverage-check.json). 380 Python checks (378 PASS, 2 Windows skip), 82 frontend и 23 PWA. Отрицательные живые исходы сохранены отдельно от успешной приёмки клуба; это не проверка всех типов и всех сценариев на реальном телефоне.

Встраивание на своём домене: сервер запускается с отдельным параметром `--frame-parent-origin https://ltybcs.com`; без него встраивание запрещено. Готовая полноэкранная страница — [deploy/demo.php](deploy/demo.php). Её нужно загрузить рядом с `index.php`, а маршрут `demo` направить на `require __DIR__ . '/demo.php'; exit;` до вывода HTML. Эта узкая настройка HTTP-заголовков добавлена после исторических category/pharmacy QA-протоколов; их SHA относятся к указанным в них исходникам.
