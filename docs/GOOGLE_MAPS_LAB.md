# Бесплатный эксперимент с Google Maps

Ветка `codex/google-maps-lab`, отдельный worktree. Основное приложение и его принятый архив не заменяются.

## Запуск

```sh
python -m app.google_lab --port 8003
```

Откройте http://127.0.0.1:8003/. Нужен Python 3.11+; сторонние Python-пакеты, Google Cloud, API-ключ и платёжный аккаунт не нужны. Backend лаборатории не делает внешних запросов и не запускает LLM, OSM refresh или 2ГИС. Для Google и уличных тайлов OSM нужен интернет браузера.

## Что сравниваем

Google-вкладка использует обычное «Поделиться → Встраивание карт» Google Maps. Три точных iframe src получены через официальный интерфейс для Байтерека, MEGA Silk Way и обзора Астаны; источник и метод записаны в `web/google-lab/embeds.json`. Параметры `pb` не сконструированы вручную. [Справка Google о встраивании](https://support.google.com/maps/answer/7101463?hl=ru).

Карта Google загружается по кнопке после уведомления о передаче Google IP и выбранной публичной области. Её можно убрать. Личная геолокация не запрашивается. Ссылки поиска и места открывают обычные [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started), которым API-ключ не нужен. Это не подключение Maps JavaScript API или Places API и не импорт Google POI в рекомендации. Точки и карточки внутри Google-карты принадлежат Google; приложение не читает содержимое iframe и не кеширует его.

OSM-вкладка использует прежний снимок 1267 исходных объектов и уже сохранённый raw Overpass. Из raw восстановлены существующие cuisine/operator/access и другие теги, без выдуманных свойств. Explicit `access=private/no` исключён из каталога лаборатории, `customers` показан с оговоркой. Отсутствие access не означает подтверждённого публичного доступа. Источник каждой локальной карточки — OSM, не Google. Есть категории, поиск, цветные точки и список; безымянные места включаются отдельно. Реальные улицы остаются внешними OSM-тайлами с атрибуцией. Ни LLM, ни источник данных основного приложения этим не заменяются.

## Почему прежняя карта выглядела бедно

342 площадки, 341 кафе, 177 парков/садов, 176 ресторанов, 106 баров, 53 ТЦ, 39 памятников, 16 достопримечательностей, 9 театров и 8 музеев. Последнее расширение добавило 529 объектов, включая 341 безымянную площадку и 139 парков/садов. В прежнем интерфейсе все категории одинаковы, подписи видны лишь при наведении, фильтров нет. Поэтому новая подложка и полнота собственной базы — отдельные вопросы. Лаборатория позволяет их сравнить.

## 2ГИС: уточнённый бюджет тестов

Пользователь предложил **5000 живых запросов суммарно на все тесты**, без сохранения ответов. 20/сутки в стабильном приложении — наш защитный предел, согласованный ранее, его можно изменить отдельно. Лаборатория Google не расходует ни одного 2ГИС-запроса и не меняет стабильный предел.

Официальная документация говорит: демо-ключ создаётся один раз и действует месяц; Places API предоставляет 1000 единиц на демо. У ключей одной подписки месячная квота общая, поэтому их количество само по себе не увеличивает пакет. Документация не даёт явного подтверждения объединения нескольких отдельных демо-аккаунтов для одной нагрузки: эту схему нельзя объявить разрешённой только по наличию регистрации. Для пула с разрешённым общим объёмом технически нужны общий счётчик до5000, отдельный остаток каждого ключа/подписки, даты окончания и лимит скорости; ключи только локально, ответы только для текущего показа. Пока новые ключи и такой пул не подключены.

Источники: [создание ключей](https://docs.2gis.com/platform-manager/subscription/keys), [единицы и общие лимиты](https://docs.2gis.com/platform-manager/subscription/pricing). Эта заметка не утверждает, что сам факт использования нескольких ключей запрещён.
