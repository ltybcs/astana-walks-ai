# ИИ-помощник с бесплатной Google-картой

Изолированная ветка `codex/google-maps-lab`, draft PR15. Главный сценарий — сообщение о прогулке, затем конкретный план с объяснениями ИИ. Карта помогает проверить выбранные места и путь. Основное приложение на8000 и исторические материалы сдачи не заменяются.

## Запуск с уже работающей локальной моделью

Если модель ещё не запущена, в checkout с уже подготовленным кешем `.local/llm` запустите только её runtime:

```sh
python scripts/setup_local_llm.py --serve --port 8081
```

В другом терминале **из checkout экспериментальной ветки** задайте параметры уже запущенного endpoint и запустите только лабораторию. Пример PowerShell:

```powershell
$env:LLM_BASE_URL='http://127.0.0.1:8081/v1'
$env:LLM_MODEL='astana-local'
$env:LLM_JSON_MODE='schema'
$env:LLM_TOKEN_PARAMETER='max_tokens'
$env:LLM_TIMEOUT_SECONDS='120'
Remove-Item Env:LLM_API_KEY -ErrorAction SilentlyContinue
python -m app.google_lab --port 8003 --llm
```

Откройте http://127.0.0.1:8003/. В уже работающем демо первая команда не нужна: второй экземпляр модели не запускайте. Лаборатория использует существующий `app.llm` и принимает для `--llm` только loopback-провайдер. Google Cloud, платные API и Google API-ключ не нужны. Python3.11+, код backend и тесты на stdlib. Для внешних карт нужен интернет браузера; Для первой установки отдельная команда `python scripts/setup_local_llm.py --download` загружает pinned runtime и веса с проверкой SHA; `--serve` их не скачивает.

Без `--llm` работает поиск и подписанный шаблонный ответ. При недоступной модели или отклонённом ответе интерфейс честно показывает fallback. `configured` в health — только конфигурация; факт успешной генерации определяется `mode=llm-grounded` конкретного ответа. Health и запуск лаборатории сами не вызывают inference.

## Что вводить

Начните с **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Уточнения старта, времени и времени суток можно задать в форме. Если текст и выбор расходятся, приложение попросит исправить противоречие, вместо тихой замены45 на60.

Распознавание контекста ограничено известными публичными ориентирами: MEGA Silk Way, Байтерек, набережная Есиля. Это приблизительные демонстрационные точки, а не текущая геопозиция человека. Для другого старта задайте координаты в форме; неизвестный адрес не геокодируется. Неоднозначное/недостающее время или место требуют уточнения. Фактически использованные значения и их происхождение показаны над ответом. Бюджет10–480 минут — верхняя граница; до3остановок могут занять меньше времени.

## RAG и соответствие задаче №1

1. Resolver извлекает однозначное время/известный ориентир из сообщения и сверяет explicit поля формы.
2. Один `Retriever(data=...)` ищет по всему безопасному набору1266POI: BM25, категории/пожелания, география и жёсткие требования. Фильтры просмотра каталога на AI-подбор не влияют.
3. Planner выбирает до3мест, оценивает переходы/посещения и возврат к старту в общем бюджете. Расстояния — прямая×1,3 при75м/мин; это оценка, не маршрутизация по улицам.
4. Существующая локальная Qwen3-4B формулирует `why` и идею `action` по отобранным фактам. IDs/цитаты/защищённые свойства проверяет прежний guard; невалидный ответ заменяется подписанным extractive. Guard не доказывает полную смысловую достоверность каждого предложения.
5. Каждая карточка показывает источникOSM, время посещения, переход, неизвестность часов/доступа и происхождение объяснения. Если подтвердить жёсткое условие нельзя, выводится честное уточнение без выдуманных мест.

Это восстанавливает главный результат task1: **куда сходить и что сделать**, с учётом места, времени и предпочтений. Требования Gemini/Vertex/MCP из task2 к этому проекту не относятся. [Матрица сценариев и ограничений](GOOGLE_LAB_SCENARIOS.md) и новая [квитанция проверки](../qa/google-maps-lab-check.json) относятся к исправленной версии. Прежняя viewer-квитанция сохранена отдельно в `qa/history/google-maps-lab-viewer-9b0217f.json`; она не доказывает AI-сценарий. Принятые PDF/MP4/ZIP исходного релиза остаются историческими материалами; новая лаборатория не выдаётся за показанную в старом видео.

## Данные и карты

Используются автоматически собранные1267OSMобъектов и связанный SHA-проверенный rawOverpass; код сборщика и происхождение остаются в репозитории. Одна explicit-private/no площадка исключена,1266мест доступны retrieval. Точные raw cuisine/operator/access дополняют факты, без выдуманных рейтингов/часов/розеток. `customers` означает необходимость проверить условия входа; неизвестный access не подтверждает публичную доступность. ИИ не опрашивает Google/2ГИС/Overpass; свежий интернет-каталог Google не подмешивается в RAG. Для обновления исходного OSM-набора есть существующий сборщик, но лаборатория использует проверенный shipped snapshot, загруженный при запуске.

OSM показывает реальные улицы, старт, нумерованные выбранные места и возврат. Пунктир — приблизительные связи, не пешеходный путь. Каталог с категориями/поиском/безымянными местами оставлен дополнительным инструментом. Неизвестные часы не становятся обещанием «открыто сейчас», тишина/розетка/доступность требуют явных данных.

Google-вкладка использует обычное «Поделиться → Встраивание карт». Три exactsrc получены официальным интерфейсом для Байтерека, MEGA и обзора Астаны; происхождение в `web/google-lab/embeds.json`. Параметры `pb` не конструировались вручную. [Справка о встраивании](https://support.google.com/maps/answer/7101463?hl=ru).

Для выбранной прогулки создаётся отдельная [Google Maps Directions URL](https://developers.google.com/maps/documentation/urls/get-started#directions-action): `api=1`, `travelmode=walking`, старт=финиш, упорядоченные остановки. Google рассчитывает собственный путь; его время может отличаться. Не все клиенты поддерживают waypoints, поэтому проверьте список остановок после открытия. Это обычная ссылка без API-ключа, а не платный Directions API. В бесплатном embed нельзя программно рисовать наш маршрут; он виден на OSM и открывается в Google по ссылке. Google-контент остаётся внутри карты, приложение его не читает и не сохраняет.

## Приватность и ограничения

Геолокация не запрашивается. Текст/выбранные координаты нужны локальному backend для этого ответа, не записываются в логи или файлы. Prompt локальной модели получает структурированные пожелания и факты выбранных публичных POI; исходный запрос и стартовые координаты туда не передаются. Это не production-развёртывание: сервер слушает толькоloopback и закрывает чужой Host/Origin, repository paths и лишние методы; APIответы no-store.

Google-карта появляется после кнопки и передаёт Google IP/публичную область. Открытие walking-ссылки отдельно передаёт выбранный старт и остановкиGoogle; предупреждение видно до клика. OSMtile requests раскрывают внешнему серверу область карты; переход к custom-координатам выполняется отдельным осознанным действием. Погода, препятствия, безопасность, очереди/билеты и фактическое открытие не проверяются. План перед аэропортом не включает дорогу в аэропорт или запас до вылета.

## 2ГИС: уточнённый бюджет тестов

Пользователь предложил **5000 живых запросов суммарно на все тесты**, без сохранения ответов. 20/сутки в стабильном приложении — наш защитный предел, согласованный ранее, его можно изменить отдельно. Лаборатория Google не расходует ни одного 2ГИС-запроса и не меняет стабильный предел.

Официальная документация говорит: демо-ключ создаётся один раз и действует месяц; Places API предоставляет 1000 единиц на демо. У ключей одной подписки месячная квота общая, поэтому их количество само по себе не увеличивает пакет. Документация не даёт явного подтверждения объединения нескольких отдельных демо-аккаунтов для одной нагрузки: эту схему нельзя объявить разрешённой только по наличию регистрации. Для пула с разрешённым общим объёмом технически нужны общий счётчик до5000, отдельный остаток каждого ключа/подписки, даты окончания и лимит скорости; ключи только локально, ответы только для текущего показа. Пока новые ключи и такой пул не подключены.

Источники: [создание ключей](https://docs.2gis.com/platform-manager/subscription/keys), [единицы и общие лимиты](https://docs.2gis.com/platform-manager/subscription/pricing). Эта заметка не утверждает, что сам факт использования нескольких ключей запрещён.
