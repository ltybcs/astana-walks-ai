# Передача второму Codex

Репозиторий: https://github.com/ltybcs/astana-walks-ai (public). Scirtor добавлен с ролью write; доступ подтверждён GitHub API 20 октября 2026.

## Текущий единый интерфейс

Основные инструкции — [README](../README.md) и [DEPLOYMENT](DEPLOYMENT.md). Текущий сервер запускается как `python -m app.google_lab` с существующими Google/2ГИС/Maps Embed настройками и локальной моделью; `python -m app.server` ниже относится к исторической версии. Общие ledger пилота не копировать и не обнулять. Scirtor временно недоступен из-за технических проблем; текущее завершение выполняет Codex A. Radkurzior выбыл после исчерпания токенов. Категории и обязательные сценарии описаны в [CATEGORY_COVERAGE](CATEGORY_COVERAGE.md).

## Исторический первый запуск

```sh
git clone https://github.com/ltybcs/astana-walks-ai.git
cd astana-walks-ai
python -m unittest discover -s tests -v
python -m app.server
```

Прочитайте `AGENTS.md` и `COORDINATION.md`. Выберите свободную задачу, запишите там владельца и файлы, затем работайте в `codex/<task>`. Сделайте отдельный коммит с назначением задачи до реализации, чтобы второй Codex видел занятый участок. При конкурирующем изменении сначала получите свежую версию и согласуйте владение.

## Сообщение для второго независимого Codex

> Работаем над задачей №1 Smart City хакатона Build with AI — помощником по прогулкам в Астане. Репозиторий private: ltybcs/astana-walks-ai. Сначала прочитай AGENTS.md, COORDINATION.md и README.md. Координируйся с другим Codex через COORDINATION.md, возьми свободную задачу и закрепи её коммитом в отдельной ветке codex/<task>. Не меняй занятые файлы и контракт API без согласования. Твой первый приоритет — реальный датасет POI, качество релевантности и проверка ограничений. Запусти тесты, зафиксируй результат в журнале и открой PR. Учебный датасет и режим без LLM должны оставаться честно помеченными.

## Следующие независимые области

| Задача | Файлы | Критерий готовности |
| --- | --- | --- |
| Проверенные городские данные | `scripts/`, `data/` | Сбор воспроизводим; источники, дата и лицензия сохранены; POI проверены выборочно |
| Качество retrieval | `app/retrieval.py`, `tests/` | Проверены 5 сценариев, строгие ограничения не теряются |
| Подключение LLM | `app/generation.py`, `tests/` | Нет выдуманных POI/свойств; при сбое работает локальный fallback |
| Демонстрация и материалы | `docs/`, отдельные артефакты | Презентация на 5–7 минут, видео демо и документ сценариев |

Перед каждым этапом обновляйте владение в `COORDINATION.md`. Ни файл, ни репозиторий сами по себе не запускают Codex по расписанию: оба независимых чата должны быть запущены пользователем и иметь доступ к репозиторию.
