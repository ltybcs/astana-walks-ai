# Приватность и достоверность

Запросы и точные координаты используются в памяти для текущего ответа. Приложение не создаёт аккаунты и историю прогулок, не применяет аналитику и не сохраняет локацию в localStorage. В форме по умолчанию смоделированная точка; пользователь может вручную указать другую.

Во временном HTTPS-демо сетевые запросы проходят через Cloudflare Quick Tunnel к локальному backend; локальная модель остаётся на ПК.

В extractive-режиме запрос обрабатывается локально. Опциональная LLM свободно формулирует объяснение и идею действия по найденным POI. Она получает только распознанные признаки интересов и публичные поля выбранных POI: название, категорию, описание и свойства. Исходный текст пользовательского запроса, координаты и название стартовой точки, расстояния, расчётное время и часы работы в этот payload не включаются. Числа и часы отображаются отдельно из backend. Локальный совместимый endpoint может работать без внешнего провайдера. При внешнем провайдере перед использованием нужно проверить его условия обработки и хранения данных. Ключ хранится только в окружении backend.

Backend проверяет структуру ответа, идентификаторы выбранных POI, ссылки-цитаты и известные рискованные утверждения. Неподтверждённые розетки, тишина и доступность не должны превращаться в обещание. Свободный текст не повторяет числовые времена/расстояния и не добавляет транспорт, кроме пешей прогулки. Этот валидатор не доказывает семантическую обоснованность каждой фразы LLM, поэтому режим и ограничения видны пользователю. При отказе провайдера или неуспешной валидации приложение использует обозначенный extractive fallback. Наличие конфигурации LLM само по себе не означает подтверждённый живой вызов.

Сборщик POI обращается к Overpass API по фиксированной городской области. Он не передаёт персональную историю прогулок, запросы или пользовательские координаты. Периодическое обновление использует проверенный последний снимок при сетевом сбое и не запускается каждым запросом пользователя.

Отдельная панель 2ГИС отправляет на официальный Places API только выбранную категорию из фиксированного списка и постоянные границы Астаны. Исходный запрос и точная локация пользователя туда не передаются. Ключ остаётся на backend в окружении либо игнорируемой `.local/2gis/api-key`. Карточки текущего ответа не сохраняются на диск, в RAG, истории или service worker; HTTP имеет `no-store`. На диске остаются только времена попыток для общего лимита 20 обращений за скользящие 24 часа. Ошибки также расходуют попытку. После закрытия страницы для повторного поиска нужен новый запрос; карточки 2ГИС не накладываются на карту OSM.

Уличная подложка карты загружается с tile.openstreetmap.org. Этот сервис получает IP-адрес и область просмотра по адресам плиток; текст запроса и координаты маркеров отдельно ему не отправляются. Первый вид карты — общая публичная область Астаны. Координаты, введённые вручную или полученные через геолокацию, сами по себе не приближают внешнюю карту: для этого пользователь нажимает «Показать начало и маршрут» после уведомления о передаче области просмотра. Разрешение браузера на геолокацию запрашивается отдельно только кнопкой пользователя. Библиотека карты поставляется локально, внешние шрифты и аналитика не загружаются. Ссылки на карточки источника открываются по выбору пользователя.

PWA сохраняет только статическую оболочку: HTML, JavaScript, CSS, манифест, иконки и локальную библиотеку Leaflet из закрытого списка. Service worker отправляет `/api/` только в сеть, не записывает запросы или ответы API в Cache Storage и не кэширует произвольные пути, URL с query string, cross-origin тайлы или прочие non-GET запросы. Плитки загружаются только для текущего вида карты с обычным HTTP-кешем браузера, без предварительной выгрузки города и офлайн-пакетов. Без связи оболочка открывается, но новый подбор требует подключения к backend. Запрос не откладывается для скрытой отправки после восстановления сети.

Время в пути оценивается геометрически. Это не проверка безопасности маршрута, доступности переходов или фактического времени на дорогу. Ночная доступность, розетки, тишина и возможности для маломобильных людей требуют подтверждённых данных. Неизвестные значения должны сохраняться как неизвестные.

Учебные POI отделены от собранных данных. Для каждого реального POI сохраняются источник и дата сбора. Статус «получено из источника» не равен полевой проверке. Сгенерированные идеи действий не должны выглядеть как факты о текущем событии или услуге. Для следующей версии нужны свежесть данных, проверка часов, исправления от владельцев мест и оценка ответов людьми.
