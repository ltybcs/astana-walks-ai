# Google live-пилот: Grounding Lite и Places New

Отдельный эксперимент `codex/google-maps-lab` / draft PR15. Основное демо на 8000, OSM-набор и исторические материалы сдачи не заменяются. Источником по умолчанию остаётся OSM; Google включается отдельно оператором и пользователем.

## Разрешение и запуск

20 октября пользователь разрешил в существующем trial-проекте aituBG только Maps Grounding Lite и Places API (New), отдельный ограниченный ими ключ и до 500 тестовых HTTP-попыток по публичным местам Астаны. Оба API включены, ключ ограничен ими. Paid-upgrade не выполнялся. Локальный лимит не заменяет состояние trial, billing-аккаунта и квот провайдера.

Ключ хранится только на backend в игнорируемой приватной runtime-папке. Не помещайте его в командную строку, frontend, URL, журналы или Git. Локальный JSON конфигурации содержит абсолютные пути; необязательный `cache_dir` включает описанный ниже архив:

```json
{
  "key_file": "/absolute/private/runtime/google/api-key",
  "ledger_file": "/absolute/private/runtime/google/pilot-ledger.json",
  "cache_dir": "/absolute/private/runtime/google/permitted-cache"
}
```

`key_file` содержит только ключ UTF-8. Каталог архива должен уже существовать и быть исключён из Git. На Linux используйте mode 0700 для runtime-каталога и 0600 для файлов. Ledger общий для всего пилота, включая перезапуски и процессы; его первичная инициализация выполняется один раз:

```sh
python -m app.google_budget --init /absolute/private/runtime/google/pilot-ledger.json
python -m app.google_lab --port 8003 --llm --google --google-config /absolute/private/runtime/google/config.json
```

Параметры существующего loopback Qwen endpoint — в [руководстве лаборатории](GOOGLE_MAPS_LAB.md). Второй экземпляр модели не запускайте. Без принятого локального ответа показывается обозначенный исходный Google summary, а не выполненная генерация Qwen.

## Что передаётся Google

Центральная форма принимает обычную фразу, например **«У меня 45 минут возле Mega, хочу короткую прогулку»**. Preview локально разрешает контекст и до согласия показывает точный `outbound_search_text` и полный `outbound_search_parameters`.

Поисковый текст строится только из категории, известного публичного района и пожеланий из ограниченного словаря. Исходное сообщение, точные GPS, число минут и время суток в поисковый текст Google не включаются. Разрешённые координаты передаются отдельно как центр поиска и WALK waypoint. Бюджет и сутки остаются локальным контекстом планировщика и Qwen; из бюджета вычисляется передаваемый радиус. Доступны отдельные публичные старты MEGA Silk Way, EXPO, Байтерек и набережная Есиля, а также совпадения локального OSM-справочника. Произвольного внешнего геокодера адресов нет. Нераспознанный адрес, отказ GPS или точка вне области Астаны дают явно обозначенный городской пример; это не местоположение пользователя.

Обычная «прогулка» означает внешний осмотр архитектуры, площадей и бульваров; она не превращается автоматически в поиск парка. Явный парк/сад или детская площадка сохраняют более узкое намерение. Для generic walk у MEGA используется точная публичная поисковая подсказка:

> Прогулочные площади и архитектура на территории EXPO рядом с MEGA Silk Way, Астана. Nur Alem — только внешний осмотр.

Это заданный приложением район поиска, а не заранее назначенная остановка или факт, извлечённый из Google summary. Начало и конец маршрута остаются MEGA Silk Way (`51.0892, 71.4074`).

Передаваемый объект включает `textQuery`, `languageCode="ru"`, `regionCode="KZ"`, `locationBias.circle` с публичным центром и `radiusMeters`, `pageSize=5`, `includeExtendedDetails=false`. Радиус равен `max(100, min(2000, floor((minutes − 10) × 60 / 2)))` метров: для 45 минут — 1050 м. Это эвристика области поиска, не расстояние по улицам. Google location bias сам по себе не гарантирует попадание в круг, поэтому приложение дополнительно проверяет координаты источников локально.

Основная кнопка Google запускает отправку после видимого уведомления о передаче стартовой области или разрешённых координат. Внутренний preview остаётся локальным. Одноразовый preview-token несёт только digest; точный неизменный контекст хранится ограниченно в RAM. Selection-token содержит только публичные IDs и подписанную политику sensitive, без адресов/GPS. Изменение источника или сообщения очищает результат, детали и маршрут и отменяет устаревшие callbacks. Автоматического повторного поиска нет; после таймаута внешний запрос мог завершиться и быть учтён.

## Выбор остановки, время и ответ

Выполняется один фиксированный поиск. Весь Google summary и все исходные source previews передаются внутри текущего потока целыми для отображения и grounding; summary не разбирается в новую базу POI.

Из структурированных координат источников выбирается ближайший кандидат внутри жёсткого радиуса каждого бюджета. Для нескольких бюджетов один поиск использует наибольший радиус; до трёх планов получают разные остановки, если они есть. Повтор той же остановки явно отмечается. Только для намерения `["walk"]` требуется также не менее 100 м прямого удаления от старта, чтобы сам MEGA/другой старт не стал остановкой той же прогулки. Для явного музея, кафе, архитектуры и других категорий такого нижнего порога нет.

Если близкого кандидата нет, `selected_place_id=null`: маршруты и Qwen не вызываются, архив grounded output не создаётся. Показываются полный исходный summary, все его источники и явное предупреждение, что подходящая рекомендация не получена.

Для каждого выбранного места выполняются два отдельных `compute_routes` с `WALK`: от старта к месту и обратно, всего до шести WALK legs за один submit. Один переход не умножается на два. Посещение и запас — предложение приложения, а не свойство места. Budget panel содержит обе длительности, посещение, резерв, итог и ссылки атрибуции Google. При неизвестном пути или превышении бюджета статус `unverified` / `does_not_fit` виден явно; положительная рекомендация Qwen не создаётся.

Только основной вариант со статусом `fits` допускает одну генерацию Qwen. Остальные варианты показывают полный неизменный Google summary и собственный расчёт, без выдачи их за отдельные генерации. Она получает полный неизменённый GML summary, все минимальные обязательные source previews (id/source_id/title/url/attribution) и локальный контекст/расчёт. Лишние photos/reviews/directions links из provider metadata в prompt не включаются; ни summary, ни набор обязательных previews не сокращаются. Инструкция просит до трёх коротких предложений и 360 символов при лимите 450 токенов; это цель генерации, без обрезки текста. Ответ относится к выбранной остановке, схема заранее связывает его с её source ID. Для обычной прогулки действие предлагается как внешний осмотр; новые интересы и обещания внутренних занятий не добавляются. Формирует один цельный ответ; guard принимает или отвергает его целиком, без переписывания слов, разбиения на старые why/action-карточки или извлечения новых фактов POI. `google-grounded-llm` означает принятый локальный текст; `google-grounding-summary` — полный исходный summary. Источники стоят непосредственно после соответствующего цельного текста. Структурная проверка не гарантирует смысловую достоверность каждого предложения.

Часы и до пяти отзывов загружаются отдельными кнопками Places New только для ID текущего подписанного выбора. В интерфейсе показываются авторы, даты, ссылки и атрибуции. Они не передаются Qwen или OSM RAG. Отзыв — мнение автора; отсутствие данных не доказывает розетку, тишину или доступность. Каждый клик делает свежий запрос; повторных автоматических запросов нет.

## Карты, сеть и лимит

Google Content показывается на отдельной поверхности. OSM-карта, каталог и прежние результаты при переключении скрываются и очищаются. Google Share→Embed загружается по собственной кнопке; выбранный маршрут открывается обычной walking Maps URL с возвратом. Google-данные не переносятся на OSM-слой. `compute_routes` не предоставляет здесь геометрию или пошаговую навигацию. WALK находится в beta: тротуары, проходы, фактический доступ и безопасность требуют самостоятельной проверки.

Ключ передаётся заголовком только на `https://mapstools.googleapis.com/mcp` и `https://places.googleapis.com`. Redirects и автоматических retries нет. Startup, health, status и preview не вызывают Google или модель. В ledger до сети атомарно резервируются все HTTP-попытки обоих data endpoints, включая MCP initialize/initialized/tools-list, ошибки и таймауты. Предел 500 сохраняется между процессами и перезапусками. Количество платных SKU может отличаться от этого технического счётчика.

Exclusive-create не перезаписывает существующий ledger. Отсутствующий или повреждённый счётчик блокирует сеть; пересоздание не даёт ещё 500 попыток. Ledger хранит лишь счётчики операций и время, отдельно от архива. QA сохраняет статусы, счётчики, хеши и публичные ID, а не provider payload.

## Разрешённое хранение

Архив включается только через `cache_dir` в игнорируемой runtime-папке. Он не раздаётся по HTTP и не входит в Git, ZIP, localStorage или service worker.

| Данные | Что сохраняется |
| --- | --- |
| Places New ID | ID из валидированного ответа Places New, бессрочно; время первого/последнего получения |
| Координаты Places New | Только реально возвращённое явно запрошенное поле `location`, на 29 дней; GML-координаты это исключение не покрывает |
| Принятый Grounded Output | Весь текст принятого Qwen-ответа неизменно, вместе с минимальными обязательными отображаемыми source previews: публичные ID/source ID, точные title/URL и атрибуции; единый артефакт на 29 дней |
| Часы, отзывы и остальные данные | Свежий показ в памяти; на диск не сохраняются. Raw GML/API summary, fallback, маршруты, Details/review payload, GML source coordinates и лишние metadata не архивируются |

`location` запрашивается в той же фиксированной маске часов, без отдельного запроса и без повышения уже используемого Enterprise SKU. Имена/адреса/рейтинги не извлекаются из Places в архив ID/координат. В отображаемых source previews сохраняется только необходимая атрибуция связанного Grounded Output.

Цельный артефакт разрешён исключительно для оценки/оптимизации производительности или отображения приложения. Он не используется для будущих ответов вместо live Google, извлечения POI/RAG, обучения, разработки или улучшения моделей/AI-систем. Нет API чтения архива для ответа пользователю. Исходное сообщение, личные координаты, ключ, prompt и сессия не записываются. Принятие guard не является сертификатом качества, а архив не служит набором для улучшения модели.

Срок 29 дней оставляет запас до потолка 30 дней. Физическая очистка выполняется при старте, обращении и ежечасно, пока приложение работает. После выключения/остановки очистка возможна при следующем запуске; удаления на выключенном ПК не обещаем. Собственные безопасные временные файлы после сбоя writer удаляются под тем же lock. Повтор того же цельного output не продлевает его срок.

Атомарная запись, общий process lock и проверки путей блокируют symlink/hardlink/небезопасный или повреждённый архив. Ошибка диска/очистки видна только санитизированной диагностикой и не меняет уже полученный live ответ. При повреждении архив не исправляется автоматически: оператор должен проверить и очистить runtime-папку. Если запись/очистка невозможна, обещание своевременного удаления не считается выполненным; это отражается как недоступное хранилище. Отключение/очистка архива не сбрасывает ledger.


### Приватный старт

Для browser GPS, своих координат и совпадений локального каталога `sensitive_origin=true`. Whole outputs и Places locations этого потока не пишутся в архив, включая последующий запрос часов/отзывов. Preview и selection не содержат старт в открытом токене. Прямая ссылка с точными координатами старта не создаётся. Qwen получает только сутки, intent, численный план без route-attribution URL и неизменный Google контекст; перед генерацией проверяется повтор точного старта в summary/source previews. При обнаружении такого повтора модель не вызывается, показывается целый исходный ответ Google. Это ограниченная проверка явного повторения, не доказательство отсутствия любых косвенных признаков местоположения.

Автоматические тесты не запрашивают реальную GPS-позицию пользователя. Геолокация проверяется mock callbacks, живые проверки — по публичным ориентирам. Нет автоматического внешнего геокодера и autocomplete; неизвестный адрес не объявляется найденным.

Исторический OSM AI head293d527 сохранён в `qa/history/google-maps-lab-ai-293d527.json` и `qa/history/google-lab-ai-runtime-293d527.json`; он не подтверждает Google live API. Прежний viewer receipt относится к отдельной ранней версии. Текущий Google-протокол должен связывать фактический source SHA, public input, статусы и ограничения. Предварительный далёкий/неподходящий результат не превращается в успешную прогулку после изменения кода. Фактические результаты связаны с source SHA в `qa/google-maps-lab-check.json` и `qa/google-live-runtime.json`; инструкция запуска сама их не сертифицирует.
