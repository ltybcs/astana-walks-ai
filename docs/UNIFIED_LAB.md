# Единый помощник: OSM, Google и 2ГИС

Текущая экспериментальная ветка `codex/google-maps-lab`, draft [PR15](https://github.com/ltybcs/astana-walks-ai/pull/15), [localhost:8003](http://127.0.0.1:8003/). Основное демо на 8000 и материалы сдачи остаются отдельным приложением.

Введите одно сообщение, например «У меня 45 минут возле Mega, хочу короткую прогулку». Старт определяется по тексту в локальном справочнике, иначе браузер получает геопозицию. Неизвестный адрес, отказ/ошибка GPS или старт вне области вызывают ошибку **до поиска и модели**. Городского примера вместо пользователя больше нет. Без длительности готовятся варианты 60/120/240 минут; без времени суток используется текущий снимок часов браузера.

После нажатия кнопки одновременно выполняются локальный поиск OSM, официальный Google Grounding Lite и один живой запрос Places API 2ГИС. Все три результата участвуют в отборе. Пустая подходящая выдача явно отмечена; при ошибке источника общий ответ ИИ не создаётся. До трёх подходящих остановок сохраняют собственные ID, факты и атрибуции. Неизвестные часы, розетки, тишина и доступ не считаются подтверждёнными. Ограниченная страница 2ГИС и пять Google-источников не являются полным каталогом города.

Google проверяет направленные пешие переходы между остановками и возвращение. Недоступная или слишком долгая точка пропускается без потери уже пригодного пути; максимум шесть запросов переходов, без повторов. Запись Google ближе 100 м к старту не становится отдельной пешей остановкой, но остаётся в полном контексте источника. Публичный ориентир маршрутизируется по своему адресу, Google-остановка — по её place ID; собственный старт и другие точки — по координатам. Время включает предложенные приложением посещения и 5 минут запаса. Один вызов локальной Qwen создаёт цельную идею готовых вариантов; переключение длительности не вызывает новый поиск или модель. Крайние пробелы сохраняются без изменения текста. Неподтверждённые оценки, например уют или репутация, отклоняются отдельно. Невалидный текст целиком отклоняется: остаются план и полный исходный ответ Google, режим обозначен явно. Структурные проверки не доказывают смысловую достоверность каждого будущего ответа.

На странице ровно одна карта Google Maps Embed, только после построения пригодного маршрута. В ней старт, остановки по порядку и возвращение; при выборе другого варианта iframe заменяется. До запроса нет карты, тайлов, внешних скриптов или каталога. Maps Embed рассчитывает путь самостоятельно, поэтому его оценка может отличаться от суммы планировочных переходов. Пешая маршрутизация Google beta; тротуары, проходы, доступ и безопасность требуют проверки.

## Локальный запуск

Нужен Python 3.11+, существующая локальная модель и локальные настройки двух провайдеров. Ключи не входят в Git. Перед запуском остановите только прежний процесс lab8003; основной сервер8000, модель8081 и туннель не требуют перезапуска.

```powershell
$env:LLM_BASE_URL = 'http://127.0.0.1:8081/v1'
$env:LLM_MODEL = 'astana-local'
$env:LLM_JSON_MODE = 'schema'
$env:LLM_TOKEN_PARAMETER = 'max_tokens'
$env:LLM_TIMEOUT_SECONDS = '120'
python -B -m app.google_lab --port 8003 --llm --google --google-config <absolute-google-config.json> --dgis-root <absolute-primary-workspace> --map-config <absolute-embed-config.json>
```

Google config: `{"key_file":"<absolute-backend-key>","ledger_file":"<absolute-existing-ledger>"}`; прежний optional `cache_dir` применяется только к историческим отдельным Google endpoints, **единый ответ никогда не архивируется**. Не инициализируйте новый ledger вместо существующего: общий предел 500 HTTP-попыток сохраняется, включая служебные MCP обращения, ошибки и таймауты. Нет автоматических повторов.

`--dgis-root` — **основная** рабочая папка с существующими `.local/2gis/api-key`, `usage.json` и `usage.lock`. Адаптер разделяет прежние 20 попыток за скользящие24 часа с основным демо; отсутствующий ledger блокирует поиск. Пулы ключей и дополнительные лимиты не включены.

Embed config: `{"embed_key_file":"<absolute-dedicated-browser-key>"}`. Это отдельный намеренно публичный браузерный ключ, ограниченный **только Maps Embed API**, с HTTP referrers `http://127.0.0.1:8003/*` и `http://localhost:8003/*`. Backend Places/GML key использовать в iframe запрещено и блокируется при старте. Maps Embed бесплатен; браузерные загрузки iframe учитываются отдельно от500 backend HTTP-попыток. На другом домене карта не авторизована до осознанного изменения ограничения.

## Передача и хранение

До кнопки интерфейс раскрывает передачу Google/2ГИС старта и ограниченных пожеланий. Исходное сообщение в эти API не уходит. Модель на loopback получает отдельные публичные факты мест, полный неизменённый Google summary и все обязательные previews; исходный запрос и собственный старт в prompt не включаются. Проверяется явное эхо приватного старта. Точная позиция передаётся Google при маршрутизации и загрузке iframe; приложение не пишет её в журналы, Git или browser storage.

Объединённый контекст/ответ/данные 2ГИС живут только в памяти запроса. Для карты используется непрозрачный RAM ticket: координаты удаляются через 600 секунд или при закрытии сервера. Нет записи в RAG, кэша ответов, prompt cache или сырых QA payload. Нужная атрибуция OSM/ODbL, Google и[2ГИС](http://dev.2gis.ru) видна рядом с результатом. Сразу после цельного текста показаны все Google previews; текст не переписывается по остановкам.

API: `POST /api/context` — только локальная проверка; `POST /api/unified/recommend` — query/context +`consent:true`; `POST /api/unified/map` — только готовый ticket; `GET /api/unified/status` — локальные настройки, общие квоты и безопасная диагностика последнего завершённого запроса, без сети. Диагностика содержит режим, статический код отказа модели, счётчики и статусы; текста, мест, ID, координат и длительностей там нет. HTTP доступен только на loopback с проверкой Host/Origin, JSON и no-store.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Offline fixtures проверяют одновременность трёх источников,0 обращений без старта, общий лимит 2ГИС, отсутствие записи смешанных ответов, один LLM-вызов, сохранение всех Google previews, реальные бюджеты с направленным возвратом, одну карту после маршрута и отмену устаревших ответов. Реальные API/GPS этими mock-тестами не вызываются. Актуальный source-bound отчёт добавляется отдельно; прежние receipts относятся к прежним исходникам.

[Maps Embed](https://developers.google.com/maps/documentation/embed/embedding-map), [биллинг Embed](https://developers.google.com/maps/documentation/embed/usage-and-billing), [Google Grounding Lite](https://developers.google.com/maps/ai/grounding-lite), [условия Google](https://cloud.google.com/maps-platform/terms/maps-service-terms), [2ГИС для AI](https://docs.2gis.com/en/api/ai/mcp-server/overview), [оферта2ГИС](https://law.2gis.ru/webapi-offer).
