# Единый помощник: OSM, Google и 2ГИС

Единый интерфейс развёрнут на основном порту 8000 и [публичном HTTPS-адресе](https://entire-burn-cricket-ashley.trycloudflare.com/); публичная оболочка, PWA и строгий отказ без старта проверены 20 октября 2026. Живые результаты поиска/модели и их границы — в [QA-протоколе](../qa/unified-search-check.json). Локальный 8003 остаётся предпросмотром той же версии; история реализации — [PR15](https://github.com/ltybcs/astana-walks-ai/pull/15). Прежнее приложение сохранено в tag `checkpoint/before-unified-2026-10-20` (`a20dc81`), а материалы сдачи сохраняют прежние source SHA и не сертифицируют объединённую версию. [Основной запуск и откат](DEPLOYMENT.md).

Введите одно сообщение, например «У меня 45 минут возле Mega, хочу короткую прогулку». Старт определяется по тексту в локальном справочнике, иначе браузер получает геопозицию. Неизвестный адрес, отказ/ошибка GPS или старт вне области вызывают ошибку **до поиска и модели**. Городского примера вместо пользователя больше нет. Без длительности готовятся варианты 60/120/240 минут; без времени суток используется текущий снимок часов браузера.

После нажатия кнопки одновременно выполняются локальный поиск OSM, официальный Google Grounding Lite и один живой запрос Places API 2ГИС. Все три результата участвуют в отборе. Пустая подходящая выдача явно отмечена; при ошибке источника общий ответ ИИ не создаётся. До трёх подходящих остановок сохраняют собственные ID, факты и атрибуции. Неизвестные часы, розетки, тишина и доступ не считаются подтверждёнными. Ограниченная страница 2ГИС и пять Google-источников не являются полным каталогом города.

Google проверяет направленные пешие переходы между остановками и возвращение. Недоступная или слишком долгая точка пропускается без потери уже пригодного пути; максимум шесть запросов переходов, без повторов. Запись Google ближе 100 м к старту не становится отдельной пешей остановкой, но остаётся в полном контексте источника. Старт и возвращение в расчёте и Embed-карте используют одни и те же проверенные координаты выбранного ориентира. Его название и поисковые алиасы служат подписью и подсказкой поиска, но не геокодируются повторно для маршрута. Google-остановка задаётся её place ID, остальные остановки — координатами источника. Время включает предложенные приложением посещения и 5 минут запаса. Один вызов локальной Qwen создаёт цельную идею готовых вариантов; переключение длительности не вызывает новый поиск или модель. Крайние пробелы сохраняются без изменения текста. Неподтверждённые оценки, например уют или репутация, отклоняются отдельно. Невалидный текст целиком отклоняется: остаются план и полный исходный ответ Google, режим обозначен явно. Структурные проверки не доказывают смысловую достоверность каждого будущего ответа.

На странице ровно одна карта Google Maps Embed, только после построения пригодного маршрута. В ней старт, остановки по порядку и возвращение; при выборе другого варианта iframe заменяется. До запроса нет карты, тайлов, внешних скриптов или каталога. Maps Embed рассчитывает путь самостоятельно, поэтому его оценка может отличаться от суммы планировочных переходов. Старт, остановки и возвращение на карте должны совпадать с планом; выбор другого одноимённого ориентира не считается допустимым отличием оценки времени. Пешая маршрутизация Google beta; тротуары, проходы, доступ и безопасность требуют проверки.

## Запрос конкретного заведения

«Я хочу в комп клуб на пару часов рядом с Байтереком» сохраняет цель `computer_club` при поиске OSM, Google и 2ГИС; словесная длительность даёт один бюджет120. Один клуб выбирается по подходящей категории и проверенному пешему пути, вместо последовательного посещения трёх клубов. Время посещения — остаток бюджета после пути туда/обратно и запаса; возможность такого сеанса, цены, оборудование и свободные места не подтверждены.

Категория 2ГИС подтверждается явной рубрикой источника, а не названием бренда или поисковой фразой. Google Grounding Lite сохраняет полный ответ и previews, но его metadata без подтверждённой категории не превращается в клубную остановку. Если подтверждённых подходящих кандидатов нет, маршрут и ответ модели не создаются; парки не заменяют клуб. Поддерживается ограниченный словарь активностей, а не универсальное понимание всех запросов; распознанная неподдерживаемая явная категория возвращает `unsupported_activity` до поиска. Общие запросы прогулки сохраняют до трёх остановок.

## Локальный запуск

Нужен Python 3.11+, существующая локальная модель и локальные настройки двух провайдеров. Ключи не входят в Git. После первого переноса модель 8081 работает отдельным процессом: при обновлении приложения заменяется только процесс 8000, туннель сохраняется. Старый общий run_demo launcher при первоначальном переключении потребовал также перезапуска той же модели; подробности в DEPLOYMENT. Полная команда 8000 с exact public-origin gate и откат — в [DEPLOYMENT](DEPLOYMENT.md). Следующая команда запускает только локальный предпросмотр 8003; замените значения в угловых скобках абсолютными существующими путями, сохранив кавычки.

```powershell
$env:LLM_BASE_URL = 'http://127.0.0.1:8081/v1'
$env:LLM_MODEL = 'astana-local'
$env:LLM_JSON_MODE = 'schema'
$env:LLM_TOKEN_PARAMETER = 'max_tokens'
$env:LLM_TIMEOUT_SECONDS = '120'
python -B -m app.google_lab --port 8003 --llm --google --google-config '<absolute-google-config.json>' --dgis-root '<absolute-primary-workspace>' --map-config '<absolute-embed-config.json>'
```

Google config: `{"key_file":"<absolute-backend-key>","ledger_file":"<absolute-existing-ledger>"}`; прежний optional `cache_dir` применяется только к историческим отдельным Google endpoints, **единый ответ никогда не архивируется**. Не инициализируйте новый ledger вместо существующего: общий предел 500 HTTP-попыток сохраняется, включая служебные MCP обращения, ошибки и таймауты. Нет автоматических повторов.

`--dgis-root` — **основная** рабочая папка с существующими `.local/2gis/api-key`, `usage.json` и `usage.lock`. По новому разрешению пользователя адаптер использует общий предел 500 попыток за скользящие 30 дней (2 592 000 секунд). Используется прежний ledger без автоматического сброса; отсутствующий ledger блокирует поиск. По явному запросу пользователя оператор однократно согласует начальную отметку с подтверждёнными провайдером 10 вызовами, сохраняя прежнее состояние и метаданные корректировки. Локально считаются все HTTP-попытки, включая ошибки, поэтому число может превышать счётчик успешных вызовов в кабинете провайдера. Ротация ключей и отдельные пулы не включены.

Embed config: `{"embed_key_file":"<absolute-dedicated-browser-key>"}`. Это отдельный намеренно публичный браузерный ключ, ограниченный **только Maps Embed API**, с пятью HTTP referrers: `http://127.0.0.1:8000/*`, `http://localhost:8000/*`, `http://127.0.0.1:8003/*`, `http://localhost:8003/*`, `https://entire-burn-cricket-ashley.trycloudflare.com/*`. Backend Places/GML key использовать в iframe запрещено и блокируется при старте. Maps Embed бесплатен; браузерные загрузки iframe учитываются отдельно от 500 backend HTTP-попыток. На другом домене карта не авторизована до осознанного изменения ограничения.

## Передача и хранение

До кнопки интерфейс раскрывает передачу Google/2ГИС старта и ограниченных пожеланий. Исходное сообщение в эти API не уходит. Модель на loopback получает отдельные публичные факты мест, полный неизменённый Google summary и все обязательные previews; исходный запрос и собственный старт в prompt не включаются. Проверяется явное эхо приватного старта. Точная позиция передаётся Google при маршрутизации и загрузке iframe; приложение не пишет её в журналы, Git или browser storage.

Объединённый контекст/ответ/данные 2ГИС живут только в памяти запроса. Для карты используется непрозрачный RAM ticket: координаты удаляются через 600 секунд или при закрытии сервера. Нет записи в RAG, кэша ответов, prompt cache или сырых QA payload. Нужная атрибуция OSM/ODbL, Google и [2ГИС](http://dev.2gis.ru) видна рядом с результатом. Сразу после цельного текста показаны все Google previews; текст не переписывается по остановкам.

API: `POST /api/context` — только локальная проверка; `POST /api/unified/recommend` — query/context +`consent:true`; `POST /api/unified/map` — только готовый ticket; `GET /api/unified/status` — локальные настройки, общие квоты и безопасная диагностика последнего завершённого запроса, без сети. Диагностика содержит режим, статический код отказа модели, счётчики и статусы; текста, мест, ID, координат и длительностей там нет. Слушатель остаётся на loopback с проверкой Host/Origin, JSON и no-store. На 8000 флаг `--public-origin` добавляет только точный разрешённый HTTPS origin; произвольные Host/Origin и Forwarded не авторизуют доступ. Публичный режим блокирует старые отдельные Google/каталожные endpoints; локальный 8003 сохраняет предпросмотр.

## Установка

Сохранены прежние manifest id/start_url/scope и иконки. Новый service worker `astana-walks-shell-v5-unified` хранит только allowlisted оболочку интерфейса; API, query strings, координаты, ответы и Google iframe не кэшируются. Старые shell caches удаляются при активации без автоматической перезагрузки текущего подбора. Без сети доступна оболочка, для поиска/модели/карты нужна связь. Системное предложение установки или меню браузера не требуют дополнительных полей в форме. Прежнее подтверждение Android Chrome относится к прежней версии; новая установка проверяется отдельно.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Offline fixtures проверяют одновременность трёх источников, 0 обращений без старта, общий лимит 2ГИС, отсутствие записи смешанных ответов, один LLM-вызов, сохранение всех Google previews, реальные бюджеты с направленным возвратом, одну карту после маршрута и отмену устаревших ответов. Реальные API/GPS этими mock-тестами не вызываются. Актуальный source-bound отчёт добавляется отдельно; прежние receipts относятся к прежним исходникам.
