# Сценарии ИИ-помощника Google Maps Lab

Источник требований: задача №1 НИЦ Smart City, страницы 1–3 предоставленного задания. Требования стека задачи №2 сюда не переносятся.

Матрица связывает требования с ожидаемым поведением и отдельным фактическим HTTP-прогоном 20 октября 2026 года. Полные синтетические входы/ответы и их хеши — в `qa/google-lab-ai-runtime.json`; итоговая квитанция связывает их с исходным кодом и индексом. Прежние viewer-проверки не подтверждают восстановленный AI-сценарий. Реальные обращения к общей локальной модели выполняются только в объявленный A слот.

## Требование → функция → проверка

| Требование task1 | Функция демо | Проверка |
| --- | --- | --- |
| Работающий RAG: поиск POI и генерация | Сообщение → resolver → retrieval → planner → локальная LLM | На exact MEGA-кейсе получить настоящий `llm-grounded`, прочитать буквальные why/action и связать квитанцию с моделью, кодом и SHA набора. `configured=true` или mock не доказывают inference. |
| Локация, предпочтения, контекст | Видимый `resolved_context` и необязательные уточнения формы | Использованы именно распознанные/явно выбранные значения. Поиск идёт по безопасному набору 1266 POI, независимо от вкладки, категорий просмотра, первых 60 карточек и переключателя безымянных мест. |
| 1–3 конкретных рекомендации | Карточки с why, action, источником и временем | Каждый ID/ссылка принадлежит выбранному OSM-набору. Идея LLM отделена от факта; неизвестные часы, доступ, розетки и детская безопасность не выдуманы. При отсутствии подходящих данных допустим объяснённый пустой ответ. |
| Учёт времени и понятный результат | Переходы, посещения и возврат в общем бюджете | Сумма соответствует `plan` и не превышает бюджет. До трёх остановок не обещают заполнить всё время. Пунктир OSM и Google walking URL не выдаются за проверенный пешеходный путь. |
| Приватность и прозрачность | Локальный endpoint, согласие на внешние карты, честный режим | Исходный запрос/стартовые координаты не попадают в prompt, файлы или логи. Google не источник RAG; iframe и передача маршрута Google требуют соответствующего осознанного нажатия. |

Ноль мест, уточнение об отсутствии совместимых точек с явным 24/7. Ночной контекст распознан из текста. |

Для каждого фактического результата A фиксирует source commit/хеши, публичный вход, resolved_context, mode/llm_status/attempts, ID/ссылки, why/action, бюджет/итог/возврат и ограничения. Свободный текст читается человеком; структурный PASS не заменяет эту проверку. Новый протокол хранится отдельно от исторических evaluator/видео/ZIP.

Три непустых HTTP-ответа использовали существующую pinned Qwen3-4B `astana-local` на loopback8081. Всего прочитано пять why/action-пар в этих трёх ответах; это не пять LLM-сценариев и не повторная сертификация исторического релиза. RAG index SHA-256: `73be2d4a48f7e56b3656648c3b0998c8b8b56533059d4e1942535660de58ebbf`. Конфликт45/60 дал400 `context_conflict`, неполный запрос дал422 `needs_context`, оба до inference. Полный suite:166 run,165 PASS,1 Windows symlink SKIP,0fail; Node offline24/24 входят в отдельную unittest-обёртку.

## Неоднозначность, ошибки и приватность

| Случай | Ожидание |
| --- | --- |
| «Хочу прогуляться»; неизвестное место; «30 минут или 60 минут возле Mega»; два ориентира без выбора | 422 `needs_context`, понятное уточнение, без тихих default 60 минут/другого старта и без inference. |
| Текст MEGA45 + explicit `minutes=60` или `origin_id=baiterek`; текст «ночью» + explicit `time_of_day=day` | 400 `context_conflict`, без inference. Совпадающие текст/поля принимаются, их происхождение видно. |
| Бюджет 9/481, дробь, bool или строка в explicit minutes; неверные координаты; повреждённый/слишком большой JSON; чужой Host/Origin | Отклонение до модели по контракту. Допустимые границы 10/480 и custom 375 передаются в planner без подмены. Репозиторий и лишние endpoints не раскрываются. |
| Модель выключена, недоступна или ответ не прошёл guard | Явный extractive/fallback с причиной, без надписи о выполненной LLM-генерации. Пустой retrieval не запускает генерацию выдуманных мест. |
| Изменение сообщения/уточнений во время ожидания; повторная отправка | Старый запрос отменяется/игнорируется. Карточки, маршрут, контекст и Google-ссылка не остаются от прежнего ответа; кнопка восстанавливается после ошибки. |
| Смена каталоговых фильтров/скрытие безымянных мест | Меняется просмотр каталога; assistant не теряет подходящие POI и не ограничивается текущими 60 карточками. |
| Custom-старт и внешние карты | Только публичные/смоделированные координаты в QA, без геолокации. Точные custom-координаты не раскрываются OSM автофокусом без отдельного уведомлённого действия; Google walking-ссылка передаёт старт/остановки только по нажатию после предупреждения. |
| Google-вкладка/маршрут | До согласия iframe отсутствует; выгрузка/смена области/возврат к OSM удаляют его. Walking URL содержит фактический порядок выбранных остановок, `travelmode=walking`, старт=финиш, без API-ключа. Google POI не читаются и не записываются в RAG. |

Новый QA должен отдельно назвать выполненные mock/offline/HTTP/CUA/live-LLM проверки и их ограничения. Успех этой матрицы не означает полевую проверку, установку на физический телефон или публикацию YouTube.
