# Исторический прогон Qwen3-1.7B

Старые отчёты, provider request/response JSON и installed manifest сохранены побайтно, без исправления результатов. Их ручная проверка качества не пройдена. Это исторические данные, а не текущая оценка проекта.

Строки `output/llm-evidence/...` внутри старых отчётов относятся к подкаталогу `llm-evidence/` этого архива. Они сохранены verbatim, поэтому буквальная ссылка на корневой `output/llm-evidence/` теперь может открыть новые данные 4B. Используйте отображение исходных и архивных путей в [archive-index.json](archive-index.json); там же приведены SHA-256 каждой сохранённой копии.

[installed-model-manifest.json](installed-model-manifest.json) фиксирует прежние веса 1.7B; он не описывает новую модель.
