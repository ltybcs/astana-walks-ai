# Фактическое мобильное демо Astana Walks

`astana-walks-demo.mp4` — готовый для ревью ролик 3:24,44, H.264, 1080×1920, 25 fps, без звука. Он содержит один последовательный проход работающего HTTPS-интерфейса (3:00,44) и отдельный 24-секундный фрагмент ручной установки. Второй фрагмент явно помечен в кадре. `astana-walks-live-pass.mp4` сохраняет основной проход отдельно.

Показаны реальные запросы: MEGA, 45 минут → NU Park, 42 минуты; кофе с розеткой → честный отказ; ребёнок, 60 минут → Парк Астана, 34 минуты; архитектура, 120 минут → Байтерек и Astana Musical, 67 минут; строгий ночной запрос → отсутствие подтверждённых мест. У трёх непустых ответов видна метка RAG+LLM, у двух отказов — шаблонный режим. Это UI-пресеты и конкретный featured-запрос, а не подмена точных сценариев отдельного формального evaluator.

Кадры получены только из вкладки настоящего Chrome при ширине 390 CSS px. Захват периодическими снимками с целевым интервалом 0,5 сек сохраняет фактические timestamps. Во время более редкого наблюдения повторяется последний зафиксированный кадр; ожидание не ускорено. Это один проход действий, а не запись рабочего стола с полным кадровым потоком. Личные окна и настоящая геолокация не использовались; старт возле MEGA смоделирован по сценарию.

`manifest.json` содержит хеши MP4, временную шкалу, способ захвата и границы проверки. `observed-responses.json` содержит все пять фактически отрисованных ответов и четыре пары why/action внутри карточек. Это DOM-свидетельства данного прохода, не raw provider JSON; provider-attempts этого видео отдельно не собирались. Сохранённый формальный 4B evaluation относится к другому прогону. Отдельные исходные tab-кадры локально сохранены, в этот пакет не входят.

Каждый кадр итогового MP4 успешно декодирован FFmpeg; ffprobe подтвердил формат/длительность. Семь `preview-*.jpg` извлечены из итогового файла и визуально просмотрены: три LLM-ответа, два отказа, ограничения и установка. Кадры приложения и полученные тексты не исправлялись. В первом действии сохранено грамматическое «в свежем воздухе». Семейная формулировка «место для детей» — широкая связь категории с запросом, а не проверка инфраструктуры или пригодности; явное предупреждение о неподтверждённых условиях остаётся на экране. Требуется независимый просмотр A перед внешней публикацией.

Инструкция установки показывает ручной путь Chrome/Firefox Android и Safari iPhone. Она не доказывает установку на физический телефон; приложение на компьютер при съёмке не устанавливалось. YouTube/Telegram не использовались для отправки. Канал и режим публикации ещё должны быть определены пользователем; локальный MP4 не заменяет требуемую YouTube-ссылку.
