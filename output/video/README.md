# Проверенные фрагменты демонстрации

Два самостоятельных вертикальных MP4, H.264, 1080×1920, без звука. Захват только настоящей вкладки Chrome, мобильная ширина 390 CSS px. 2 наблюдённых кадра в секунду, фактическое течение времени сохранено; при кодировании кадры повторены до 25 fps. Подписи поясняют наблюдаемое действие. Личные окна и рабочий стол в запись не входят.

- `astana-walks-socket-demo.mp4` — 32 секунды: выбор «Кофе и работа», реальный запрос через существующий HTTPS и отказ из-за неподтверждённой розетки. Карточек нет, виден режим «ПОИСК + ШАБЛОННЫЙ ОТВЕТ». Это подтверждение строгого ограничения, не live LLM.
- `astana-walks-install-demo.mp4` — 24 секунды: единая кнопка «Установить» и ручная инструкция для Chrome/Firefox на Android и Safari на iPhone. Снято локально с UI commit72cc27d. Нативное предложение перед съёмкой отменено, приложение на компьютер не устанавливалось. Фрагмент не доказывает установку на физическом телефоне.

`capture-manifest.json` содержит SHA-256 MP4, фактические времена кадров, подписи, формат и границы проверки. `*-preview.jpg` — контрольные кадры, декодированные из MP4 и просмотренные перед передачей. Исходные отдельные кадры не включены в этот пакет.

Основной непрерывный RAG-ролик ещё не готов: ручная проверка текстов прежней модели Qwen3-1.7B дала quality_pass=false. Эти фрагменты не заменяют финальную проверку новой модели или итоговое видео всех сценариев. Для YouTube ещё нужны канал и режим публикации, определённые пользователем. Ничего в YouTube/Telegram этим PR не отправлено.
